# Changes

## 1.3.1

- **One option for the window style:** the switch "Windows in the game's look" is now the choice "Window style" with "Don look" and "Blizzard look", named the same in every Don addon. Your setting stays as it was. `/vd diag` and the report name it too.
- **Shared Don library:** updated to the current version of the Don addons.

## 1.3.0

- **Vitaldon in the game's look:** the diagnostics window and the report window now look like the game's own windows: the game's frame, tabs, buttons and lists. The numbers on the unit frames do not change. The options open in the game's settings (Options > AddOns > Vitaldon). This is the new default; the Don look is one switch away under General, "Windows in the game's look".
- **Shared Don library:** updated to the current version of the Don addons.

## 1.2.2

- **Cleaner text in narrow places:** text that is shrunk to fit keeps one font and size, also after the game window changes its size.

## 1.2.1

- **Shared Don library:** updated to the current version of the Don addons (tooltips with a head line and class symbols).

## 1.2.0

- **New look:** the diagnostics window (`/vd diag`) in the style of the Don addons: tabs Overview, Bars, Values and Errors, problems on top with a button where Vitaldon can fix them, the bars as a table with their details on the right, the report in the shared copy window.
- **Live preview:** the options window shows your player frame and your target with sample values in your settings. Every change shows at once; with the mouse on a frame group's option you see that group.
- **Colours:** "By health" uses the green, yellow and red of the Don addons; class colours are the same as in the other Don addons (the shaman is blue in Classic Era too).
- **One options window for all Don addons:** switches, sliders, lists, a picture and an explanation for every option, a search over all Don addons. The gear button and the slash command open it on this addon's section. Blizzard's AddOns page only shows the status and a button.
- **Window size:** all Don windows share one scale, 80 % by default, set from 60 to 110 % under General > Window in the options window. Saved window sizes are reset once, places stay.
- **Addon list:** the addon has its own logo in the game's addon list.
- **Update note:** new files, so restart the game after updating (a /reload is not enough).

## 1.1.2

- **No new addon needed.** Vitaldon works on its own as before.
- **Lighter:** the values still change at once on the game's events; the regular check now runs twice a second instead of four times. Raid-style party frames follow a new order within half a second.
- **Shared base:** options and window style come from DonCore, the common base of the Don addons. Nothing changes for you.

## 1.1.1

- **Look:** windows and buttons use the shared style of the Don addons (same as Questdon, Guildon, Luredon).

## 1.1.0

- **Translations:** French, Spanish (Spain and Latin America), Brazilian Portuguese, Russian, Korean and Traditional Chinese.
- **Fonts:** in Russian, Korean and Chinese clients only the game font is offered, because the other fonts lack those letters.
- **Decimal sign:** values use the decimal sign of your game language.

## 1.0.1

- Published through the automatic release pipeline, like Questdon and Luredon. No changes in the addon.

## 1.0.0

First release on CurseForge.
